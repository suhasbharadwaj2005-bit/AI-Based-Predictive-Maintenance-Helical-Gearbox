# Dataset

This project uses the PHM Society 2009 Gearbox Dataset.

The dataset contains publicly available experimental gearbox
condition-monitoring data collected using accelerometers and
a tachometer.

The experimental setup includes different gearbox operating
conditions and gear configurations, including helical gears.

The original dataset files are not stored in this repository
because of their size.
